# キラームーブ ON/OFF 複数局面比較

`npm run measure:killer-move-suite-comparison -- [fixed|timed]` は、PR #138 の比較APIと固定3局面を再利用する研究用CLIです。baseline=`killer-off` とcandidate=`killer-on`の差は`AlphaBetaSearchOptions.killerMoves`だけです。両方とも標準評価、通常`standard`順、静止探索追加1手・`original`順です。

各局面は3回のウォームアップと8回の本測定を行います。本測定のOFF/ON先行は4回ずつで、同じ探索時計やスナップショットは共有しません。fixedは通常深さ3、timedは最大深さ4と呼出しごとに独立した1,000msです。深さ1は既存の最低保証であり、timedの1,000msは厳密な実行上限ではありません。

JSONには全試行の選択手、評価、完了深さ、通常探索の訪問局面数・cutoff・skip、経過時間、time outを残します。局面別は8回中央値、全体は深さ・時間が局面中央値の中央値、訪問局面数・cutoff・skipが局面中央値の合計です。差分はON - OFFです。

fixedでは各検索が既存のPV・評価内訳・合法手検証を通り、ON/OFFの評価不一致は比較失敗として扱います。timedでは完了深さ・評価・選択手の完全一致を要求しません。時間や訪問局面数はCIの性能条件にせず、1回または同一機の反復だけから棋力、Elo、統計的有意差、既定有効化を結論しません。
