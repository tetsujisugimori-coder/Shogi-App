# 自己レビュー記録

これは第三者レビューではない。#202/#204/#206の契約と今回のコード・保存原本を別観点から照合した。

元rootを維持した合法rootActionの絞り込みだけを既存fixed APIへ渡しており、通常再帰・q再帰・手順順・評価・SearchValue・root plyの算出は既存実装を使う。rootActionとtrace callbackが未指定なら探索の意味を変えない。UI/Workerからこの指定を追加していない。フックは原状態への参照を受けるのでread-only契約を明記し、診断側は入力hashの前後一致を検査する。

候補ごとの完走値を全窓で取り、root側のalphaを引き継いだ上限値と分けた。最良同値群はSearchValueで照合し、元の合法手順で先頭を選ぶ。有限exactと勝敗証明のexactを混同せず、evasion capの静的近似を仕様欄に残した。判定器と証明検証器は変更していない。固定探索中断後の途中候補はtraceに残ってもcompletedDepth=0/result=nullとし、正常なtimed反復後の次反復timeoutの既存契約に混ぜない。

traceの全状態を無制限に持たず、1000件/512KiBで省略する。全候補の値・stop/cutoff集計・返却窓はtrace本体の省略と別に保存する。記録上限は探索上限ではない。保存されたtraceはrootからの合法手順を持ち、hash・手番・王手・持駒・静的内訳を再計算する。PVは元rootからのplyと予算を再構成する。PV末端理由はこの再構成、木全体の実際の停止理由はフック集計という違いを本文にも記載した。

局所比較は元rootから1手後を保存入力から再生し、静的/捕獲q/通常1+q/応手固定を比較した。通常APIで視点が後手になる値は先手へ戻す。局所PVのplyは1開始。main matrixでは候補を含む深さを既存APIのまま使うため、視点や終局距離の変換を必要としない。

元原本は保護hashで検査し、測定source snapshotを別保存した。本測定後は製品・診断の計時経路を変更せず、派生結果・検証原ログ・説明文だけ追加する。予備の未commitソースと本測定SHAは区別する。

残る制約は、人工局面の実戦到達可能性、共有ルール/評価そのものの誤り、有限horizonの先の全応手と勝敗、上限で省略した木の詳細、OS/JIT/GC等を固定していない診断時間。通常深さd4で差が縮む事実も記載し、d3の大差だけを強調して製品採用を確定しない。
