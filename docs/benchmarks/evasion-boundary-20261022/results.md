# 結果と原因の切り分け

この局面の有限評価差の主要因は、**王手回避後の非捕獲の成りがq対象外になり、通常探索d1の外で静的評価へ止まること**だった。既存の王手回避追加0/1/2は同じ深さで候補値・選択を変えなかった。通常探索d2で順位が初めて反転する。ただしd4では差が1点に縮む。これは有限評価の原因診断であり、勝敗の誤選択確定・一般棋力向上の証拠ではない。今回もProvenError 0、#206の両候補unknownを維持する。

## 最初に変化する境界と局所比較

1. 元rootは王手中、静的値−1014。玉(8,4)→(8,3)で先手の王手を解消し、後手非王手、静的値−1005。内訳はmaterial −1000、pieceSquare −3、kingSafety −2、undefendedPieceSafety 0。
2. この後手局面は合法な捕獲が0。製品d1から入ったqは予算1を残したまま`no-tactical-candidate`で止まり、後手の非捕獲手を読まない。extra1/2も後手が王手を受けていないので追加しない。q深さを使い切ったための停止とは異なる。
3. 同じ完全状態で通常探索残りを0→1にする（q1/extra0/評価等を固定）と、飛(4,4)→(6,4)成を読み、−1205になる。この手は合法・非捕獲・非王手で、持駒は変わらない。materialが−1200になり、pieceSquare −2、kingSafety −3。総計の200点差は主に成りのmaterial差であり、未知の評価項目を測ったとは説明しない。保存済み参照PVからこの応手だけを固定した再探索でも−1205を確認した。
4. 玉(8,4)→(7,3)の直後は−1006。q1は同じく捕獲0で−1006のまま。通常1+q1の最小応手は玉(0,8)→(0,7)、値−1006。保存d3参照の飛(4,4)→(4,3)王手を固定すると、静的値はいったん−1014となり、qの回避で玉(7,3)→(8,2)を読んで−1005へ戻る。王手応手を読む既存qはここでは働いている。

以上は通常深さの1条件変更に対応する限定比較であり、深さ2の主変化だけから全応手の勝敗を証明したものではない。候補を含むroot総深さは前者の停止がnormal1+q1、再探索がnormal2+q1。局所APIの後手視点は元rootへ符号を戻し、局所PVは元rootからのply1開始で記録した。

normal d3では選択候補のPVが玉(8,3)→飛(6,4)成→玉(8,2)、静的列−1005→−1205→−1203。代替は玉(7,3)→飛(4,3)王手→玉(8,2)、−1006→−1014→−1005。normal d4の代替PVは玉(7,3)→後手玉(0,7)→先手玉(6,3)→飛(8,4)成となり、成りの−200が後のply4に現れる。有限d3の198点差は深い読みでも保持されると断定できず、d4では1点差に縮んだ。

## 仮説別の結論

|仮説|結論と確度|
|---|---|
|既存回避拡張で改善する|今回のd1〜4/extra0〜2では値・順位・選択が不変。該当する王手境界で追加を消費しない。効く証拠なし。|

## 次の製品改善候補（今回は実装しない）

第一希望は **q候補へ非捕獲の成りを限定追加する実験** 一つに絞る。今回除外された具体的な手を対象にし、合法性・手数上限・時間制限の契約を維持し、同じ診断でd1と深い参照の差を調べる。改善が確かめられるまで製品既定は変更しない。

次善策は通常探索をd2以上に確実に到達させる予算配分の検討。今回の順位反転を再現したが、全合法応手への仕事量が増え、時限下で到達を保証できない。採用しない案は今回の既存evasion追加量増加（該当局面が非王手で働かない）、同点順の変更（主要2候補は非同点）、評価重み調整（horizonと手の対象範囲の差を重みで埋める根拠がない）。いずれも一般棋力向上を主張しない。
