# W1i 独立レビューの範囲

担当BはW1h原票43件を直接読み取り、旧metadataの実行stdout/stderr SHAと一致を確認。今回保存担当AのPASSだけを流用せず、GitHub固定版4公開ログ、私有4raw、Library保存2ZIPを直接取得して検算した。生の監査票は私有領域、公開用結果はretrieval-verification.jsonとpublication-audit.json。

同一所有者・資格情報・実行基盤の共有を明記し、SOLO_STANDARDの限定技術監査。人的独立性や別資格情報の独立性PASSではない。

helperの独自12反例の初回は10期待一致、2件で非canonical名を受理した。P3として指摘し、同じ入力のまま検査器を修正。旧入力と初回結果を保持し、同一12入力で12/12期待一致を確認した。検査器SHAは `01101f32a111835fa64a205b762f2c794796e4c232e717ccd6238337a01e9664`。この補助器のP3は限定CLOSED。非展開型検査器のため、実パストラバーサルや実害の発生を主張しない。

固定HEAD提出後の別担当による読戻し・最終審査はPR #218の正式レビューに記録する。本ファイルは作成時点のレビュー履歴であり、その後の固定HEAD確認を先取りしてPASSにしない。

## 報告器の訂正履歴
初回GREEN JSONには旧REDの `pass` フィールドが残り、新判定が `pass_` に記録された。期待値や入力を変更したものではない。旧JSONは生の履歴として保持し、訂正版で旧値を `previous_pass`、現在値を `pass` と区別する。旧JSON単独の `pass` を最終採点に使用しない。
