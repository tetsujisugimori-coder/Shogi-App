Findings fixed before measurement: alpha-beta did not forward the new trailing q arguments (caught by two new interruption tests); required internal return flag broke an existing mock's type; rotation initially used sequence modulo 3 rather than trio index. The measurement commit contains the fixes. The root partial test was strengthened so the capped first result is approved before the next result expires, avoiding a false positive from merely rejecting a late first result.

The offline position-report script was added after the measured commit and reviewed separately. It reports dynamic change counts, rather than assuming that future runs will have unchanged actions. It does not change product code, fixtures, timing data or measured conditions. All measured product/runner source bytes remain in sources.json.

Final artifact review found that core.autocrlf=true would change JSONL newline bytes in a fresh Windows checkout and invalidate saved raw hashes. The dedicated evidence directory is now marked -text in .gitattributes, following the repository's existing diagnostic-byte preservation precedent. This also keeps derived Markdown equality audits stable. Measurement bytes were not rewritten.

Residual limitations: no external engine correctness proof, no proven wrong selected move in this frozen set, no positive playing-strength result, no steady performance guarantee, and no timed-run partial/fallback observations (controlled-clock regressions cover them). A locally timed-out existing 528-snapshot harness test uses injected mock searches, not the changed engine; this supports separating it from engine correctness but does not turn the failed full check into a pass.
