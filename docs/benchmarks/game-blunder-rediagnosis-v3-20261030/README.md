## 判定・原因

CONFIRMEDは、実手の敗北と代替手の勝利を独立検証済みの全合法応手を含む証明で示した場合に限るべきだが、この試作は証明器を接続しておらずCONFIRMEDを出さない。有限評価差だけで確定しない。SUSPECTEDは中断なし・同一深さ・有限子評価で代替優位300以上。NOT_CONFIRMEDはその有限比較範囲に限り差が300未満であり、正しい手という意味ではない。INDETERMINATEは候補選択・子探索の中断、partial、深さ差、非有限や欠測。NOT_RUNは元24以外または上限到達。子局面は相手手番のため差を `actual - alternative` として元手番視点へ反転する。無限大はJSONで明示的なタグへ変換し、数値差を作らない。閾値300は歩100点の3枚相当の便宜上のトリガーで、100/300/500の感度について今回の有効比較が0件のため実戦結果への影響は判定不能。

全56件の判定はINDETERMINATE 24、NOT_RUN 32、その他0。特徴ラベルはA 21、B 1、C 3、D 1、E 0、F 11（重複あり）。参照rootは24/24が時間切れ。元探索の完了深さ分布（56件）は0:15、1:37、2:2、3:2。旧疑い4件は全てINDETERMINATEへ変更したが、これは安全な手と判明した意味ではない。詳細はreport.mdとJSON。

原因仮説は各候補にコードの参照先と状態を保存するが、いずれも対象局面で原因を特定する比較実験をしていない。SEE、静止探索候補/打切り、通常探索深さ、時間、評価、手の並べ替えは追加検証が必要。合法手・王手処理とその他は根拠不足。既存SEEは合法な取り返しを処理し、今回のstandard orderingではSEEを呼ばない。コード上の関連は因果関係の証明ではない。
