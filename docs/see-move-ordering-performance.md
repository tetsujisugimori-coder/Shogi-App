## 性能判断とマージ判断

- 駒取り0～1手の並べ替えではSEEが0回。singleCaptureの深さ3全体でも7→0回となり、無駄の除去は確認できた。2手以上の比較は各候補1回、元順タイブレーク・負値の保持・先後・カスタム表を自動テストで維持する。
- 既存専用局面は43.041→33.511ms（約22.1%減）、multipleCapturesは21.317→19.005ms（約10.8%減）。一方、初期局面は116.630→118.060ms、singleCaptureは27.645→28.380msで、実時間改善は観測していない。後二者の測定範囲は前後で重なる。
- 初期局面のSEEは59→58回とほぼ残る。成り／不成を含む複数の合法捕獲がある場合には、要件どおり比較を維持している。修正後も旧mainより約52.1%遅く、100msの完了深さはmainの3から2へ下がったまま（全7回）。時間制限探索の完了深さは、今回修正による改善を観測していない。
- 固定深さの正しさ・決定性を保つ修正としては有効だが、SEEを既定有効にするPR全体の性能問題を解決したとは判断しない。**現状の既定有効のままのマージは保留推奨**。
- 次の選択肢は (1) SEE手順並べ替えの既定無効化、(2) 利益を測定できる条件でのみ有効化、(3) 別PRでSEEの軽量化。今回はこれらの設定追加・条件拡張や、キャッシュ・差分更新・置換表へ範囲を広げていない。
