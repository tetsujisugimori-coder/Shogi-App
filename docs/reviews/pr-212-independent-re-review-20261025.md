## 2. P2指摘への対応

### P2-1: 部分対応を受け入れ（次善策）

対象:
- `src/domain/shogi/quiescenceSearch.ts`
- `src/domain/shogi/quietPromotionSelection.ts`

候補選別をstand-patより前に実行する順序は維持された。既存契約では、候補が0件ならcutoffは増えず、候補がある場合のstand-pat cutoffではskippedActionCountに**実際に選別された候補数**を算入する。選別を先に省略してしまうと、この統計や診断カウンター、stop reason、中断確認の意味を変えるため、単純な処理順入れ替えを避けた判断は妥当。

実施された限定改善は、敵玉位置の取得を最初の合法な非捕獲成り候補が現れた時点まで遅延すること。該当候補が0件の場合は玉位置走査0回、複数候補でも1回とする。既存の選別基準、評価、PV、統計、中断確認、王手中の全応手を維持している。

**残存:** 非捕獲成りが存在する局面では、stand-pat cutoff可能でも利き・取り返し概算や候補のソート費用が残る。第一希望の全選別省略は未達だが、互換性を壊さない次善策として受け入れる。

### P2-2: 解消を確認

対象:
- `src/domain/shogi/quietPromotionSelection.ts`
- `src/domain/shogi/twoPlyAlphaBetaAi.ts`
- `src/domain/shogi/quiescenceSearch.ts`

`resolveQuietPromotionSelection` により、`maxCandidates` を所有プロパティ（own）から1回だけ読み、正の安全整数として検証したうえで、`{maxCandidates}` の通常データオブジェクトへ正規化する。αβ入口とstandalone q入口が同じ正規化処理を使うため、検証後のスプレッド複製で非列挙プロパティが落ちる不整合は解消されている。

- 通常、非列挙、null prototypeのown値: 受け入れる。
- 継承値しかない設定: 公開入口で拒否する。
- null、配列、欠落、未知のownキー／Symbol、不正数値: 拒否する。
- `undefined` は省略として扱い、全候補ONとの相互排他を維持する。
- TT identity、固定探索、時間制限探索、standalone qに関する新規テストがある。
